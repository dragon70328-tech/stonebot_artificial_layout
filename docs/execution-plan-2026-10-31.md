> 来源：2026-10-31 经营讨论 + Citizen 项目人工/系统排板对比验证。
> 本文是当前阶段的执行总纲：所有投入围绕"把已验证的节省变成可复制的生意"。

## 二、定位：一个生意，两个价格

- **对内：报价武器**。自用最新版，材料成本优势转化为中标率和利润率，不外传。
- **对外：卖服务，不卖软件**。收 DXF → 交审图结论+排板方案+板数清单 →
  按项目收费，定价锚定已验证节省的 10%~20%；可试"基础费+节省张数提成"。
- **入口场景：承接商报价**。报价阶段要的是快而准的板数，风险低、频率高；
  中标项目自然转化到生产级排板。
- **明确的边界**：划定不销售的地理范围/客户名单（本地直接竞争者）。

## 三、技术投入只押三件事

1. **确定性闭环（最高优先，对外接单的前置条件）**：
   ConfirmedDrawing 物化 → NestingRevision 版本化 → 统一验证器 →
   排板回读门禁 → 认证确定性模式。客户确认编号图后再排板的人工门写进
   服务合同（质量流程 + 法律责任边界）。
2. **ST-8 出材率专项（单点回报最大）**：
   - 历史 1946 件基线：73.35% / 570 张；
   - 当前 2018 件基线：**73.262% / 588 张**，面积下界 431 张；
   - 2026-11-05 已恢复“禁止旋转 + 全矩形”的固定朝向矩形快通道：
     585 张 / 73.64% / 排板约 3.9 秒；
   - 同一数据上启用固定朝向矩形快通道与逐板束搜索同台竞争：
     580 张 / 74.27%，随后用 HiGHS 对候选板型做整数配比优化：
     **578 张 / 74.53% / 约 13 秒**；
   - 578 张方案的后处理几何/刀缝错误为 0；29 张需要非 guillotine 切序，
     按“省料优先”接受并单独记录；
   - 下一步攻关板型配方、尾板合并非贯通板，目标按
     2018 件口径逐步向 575 / 570 张压缩。
3. **服务门户自助化**：客户上传 DXF、查状态、下载结果，无需教学。
   MCP 多平台适配（Claude/Kimi/云端画像包）推迟——那是内部操作员的
   效率工具，不是客户触点。

## 四、数据资产即护城河

- 服务化红利：每个外部项目的图纸都流过系统，画像库随收入增长。
- 三个经营指标：新图纸画像命中率（应升）、新增画像率（应降）、
  单均交付工时（决定服务毛利）。
- 找回 7 个缺失夹具源图；citizen 案例收口；案例库 = 质量门禁 + 销售物料。

## 五、90 天节奏

- **第 1 个月**：citizen 案例定稿（确认小材料口径、出 Word 版）；
  确定性闭环开工（`_confirm_numbering` 物化 ConfirmedDrawing）；
  内部报价流程全面接入系统。
- **第 2~3 个月**：2~3 家地理上不竞争的厂/承接商试点，首单即收费；
  跑通"收图→确认→交付→收款"全流程，记录每单工时；服务条款含责任边界。
- **第 3 个月末复盘**：单均工时、画像命中率、复购意愿，决定下一步——
  门户自助化投入 / 招第一个交付人 / 扩品类（岩板为同工艺自然下一站）。

## 六、纪律

- 暂不融资：资本需求小，外部资金只会带来不需要的增长压力；
  10 个外部付费客户后再评估。
- 对外交付前必须完成确定性闭环第一层（确认快照 + 统一验证 + 回读门禁）。
- 画像库入库标准不变：画像 + fingerprint + expected_counts + notes +
  已验证案例，五件齐全。
