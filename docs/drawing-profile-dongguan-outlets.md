# 东莞奥特莱斯图纸画像

## 目的

记录东莞奥特莱斯 DXF 的读图规则，后续遇到类似图纸时先匹配该画像，减少人工清理和反复校对。

## 画像规则

- 面板边界：
  - 优先读取 `HATCH`。
  - 没有 `HATCH` 时，读取 `石材分缝` 层的 `LWPOLYLINE`。
  - `石材分缝` 层上的 `LINE` 段如果首尾相连，拼成一个封闭面板。
- 编号图层：
  - `石材文字`
  - `石材编号`
  - `石材箱号`
- 标签规则：
  - 正则：`^(?P<material>\d{2}B)-?(?P<shape>\d+)$`
  - `01B`、`02B` 等为材料。
  - 材料后面的数字为形状编号。
- 编号归属：
  - 先使用编号文字插入点所在面板。
  - 若一个面板内有多个编号，取文字包围盒落入该面板比例最大的编号。
  - 插入点不在面板内时，再按文字包围盒重叠比例补配。
- 排除实体：
  - `CIRCLE`
  - `INSERT`
  - `DIMENSION`
- 排除文本：
  - `ST-*`
  - 区域说明文字
  - 编号前缀说明文字

## 配置文件

- 实际可加载配置：`drawing_profiles/dongguan_outlets.json`
- 本地实现：`src/drawing_profile.py`

## 后续迁移到 SaaS

1. 上传图纸后调用 `analyze_drawing()` 生成指纹。
2. 使用 `match_profile()` 匹配已有画像。
3. 命中后按画像读取面板和编号。
4. 用户修正后更新画像版本。
5. 新画像存入画像库，供后续图纸复用。
