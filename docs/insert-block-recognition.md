# INSERT 块识别

日期：2026-11-14

## 目标

让以图块方式绘制的 DXF 也能进入 StoneBot 的确定性读图闭环，同时不改变原位
DXF“源图副本 + 重分层 + 编号”的交付原则。

## 识别规则

- `INSERT` 按世界坐标展开，支持平移、旋转、非均匀缩放和 MINSERT 行列阵列。
- 支持嵌套块；块内再插入块时递归展开。
- 块内实体的 `0` 层和 `BYBLOCK` 图层/颜色继承外层引用。
- 每次块实例展开产生稳定的实例级虚拟 handle；同一块的多次引用不会互相覆盖。
- 展开后的实体统一参与封闭图形、孔洞层级、编号、材料标注、厚度、审图、
  机器就绪检查和在线预览。
- 循环块引用、超过 32 层嵌套或超过 20 万展开实体时抛出明确错误，不静默截断。

## 启用方式

通用、无画像的 `read_dxf` 默认展开 `INSERT`。

已有项目画像默认不展开，避免把图框、尺寸符号、家具或注释块识别为规格件。
确认某项目的块确实承载规格件后，在画像 JSON 中设置：

```json
{
  "expand_insert_blocks": true
}
```

画像提议工具检测到 `INSERT` 时会建议开启，同时要求人工确认注释块和符号块
不会被误判。

## 原位 DXF

源图中的真实 `INSERT` 和块定义原样保留，并归入 `BLOCKS` 层。块内识别件的
直接源 handle 在源 modelspace 中并不存在，因此写入端补写对应的 `OUTER` /
`HOLES` 核对几何、`NUMBERS` 和材料注释，并组成可整组选择的 GROUP。

## 门禁

`tests/test_dxf_insert_blocks.py` 覆盖：

- 嵌套块与非均匀缩放；
- 块内椭圆孔和编号；
- MINSERT 每个实例独立编号；
- 无画像通用读图默认展开；
- 循环块 fail closed；
- 原位 DXF 保留 INSERT，并输出 OUTER/HOLES/NUMBERS。
