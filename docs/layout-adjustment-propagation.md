# 人工排板调整传播

## 目标

允许用户调整一张大板内的规格板位置，再把同样的布局关系应用到其他同类大板。
该功能用于快速复制人工发现的圆盘锯让刀通道、共边和加工便利布局。

## 输入

- 用户从 StoneBot 排板 DXF 另存出的调整文件；
- 样板大板编号，例如 `--reference-sheet 149`；
- 输出 DXF 路径。

系统不修改源 DXF，也不接管用户原始 CAD 文件。

## 识别口径

每张板由 `SHEET_BORDER` 外框和 `Sheet_n` 标签识别。每个规格板必须仍是一个
独立 GROUP，组内包含 `OUTER`、`HOLES` 和 `NUMBERS` 实体。

同类板的默认条件是：

```text
大板尺寸相同
+ 规格板规范形状多重集完全相同
```

规范形状忽略平移，但保留尺寸和旋转方向。不同大板中的板件编号可以不同。

## 传播方式

样板板中每个规格板的最终相对包围框位置，是目标板对应形状的最终位置。系统将
目标 GROUP 整体平移到该位置：

- 只做刚体平移；
- 不改旋转；
- 不改编号；
- 不改孔洞；
- 不改 ARC/CIRCLE/bulge/SPLINE 实体类型。

若样板中有多个完全相同的形状，按位置稳定排序进行一一对应。

## 安全门禁

每张目标板先在内存中构造完整候选布局，然后检查：

- 所有规格板位于大板边界内；
- 规格板之间没有面积重叠；
- 编号文字仍在其外轮廓内；
- 孔洞仍属于对应外轮廓；
- 每个形状的目标数量与样板一致。

任何一项不通过，该目标板整体跳过，不进行部分移动。

## 输出

```text
<原文件名>_布局调整传播.dxf
<原文件名>_布局调整传播.json
```

JSON 记录样板板、匹配板、已更新板、跳过原因和移动 GROUP 数量。

## CLI

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\apply_layout_adjustment.py `
  "用户调整后.dxf" --reference-sheet 149
```

显式指定输出：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\apply_layout_adjustment.py `
  "用户调整后.dxf" --reference-sheet 149 `
  --output-dxf "D:\交付\项目_布局调整传播.dxf"
```

## 边界

- 当前只匹配完全相同的规格板库存；
- 当前只传播平移，不支持用户同时修改旋转或几何；
- 不自动增加或减少大板数；
- 不把用户人工排板 DXF 作为测试夹具或插件发布内容。
