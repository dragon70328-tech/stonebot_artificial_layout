# 悦府 43-44 层立面：审图与规格板提取规则

适用范围：住宅精装石材立面施工图（多立面排图、0 层堆叠、非实线标注边部
做法、斜线洞口符号、轴测示意）。沉淀自 2026-11-01 的逐立面核对。

## 一、识别规则

### 1. 非实线不是废线

| 线型 | 含义 | 处理 |
|---|---|---|
| ZIGZAG | 撇底 45 度留 1mm | 参与轮廓；原位图可转实线并注明 |
| GAS_LINE | 撇底 45 度粘接 R2 圆边 | 同上 |
| FENCELINE1 | 见光边 | 同上 |

禁止把非实线直接过滤掉：会导致轮廓不闭合或漏边。

### 2. 两条斜线相连 = 洞口

- 等长对称（Z 形）→ 过道/通道。
- 单峰（V 形）→ 窗户。
- 斜线本身不参与二维轮廓；用两条墙线之间范围作为洞口。

### 3. 25° 等长平行线组 = 轴测示意

- 典型长度 380，成组出现，旁边常有"层板 三面见光…"文字。
- 不参与二维轮廓；用于表达板厚/见光面/深度。

### 4. 大半径圆 = 详图指示框

- 圆内有多条构造线、旁边有放大详图时，判为索引框，不参与孔洞。

## 二、板件展开规则

### 1. 壁龛（矩形内凹）

输入：立面开口 W×H、深度 D、层板数量 n、板厚 t。

输出：

- 背板 W×H×t ×1；
- 侧板 D×h×t，每侧按层板分段（常见 400 高一段）；
- 层板 W×D×t ×n；成活尺寸按圆边收口扣减（R2 → 每边 1mm）。

注意：侧板分段之间的缝隙就是层板位置；不要画在背板上，按轴测朝向放在
背板旁。

### 2. 凹槽（无背板）

输入：开口 W×H、深度 D、板厚 t、跨度数 k。

输出：

- 左右侧板 D×H×t ×2；
- 上/下横板 D×(W/k)×t，各 k 件；
- 无背板（以顶部剖视图确认）。

表达：横板/侧板在原位图中只有 18 宽投影，不以投影条当规格板；在图下
按真实尺寸列表，Excel 保留全部行。

### 3. 公称尺寸与几何尺寸

当分段总长不能被跨数整除（如 3506/3=1168.67），绘图常出现
1168/1168/1170 的几何分段，但尺寸标注统一写 1169。
**规格按标注的公称值 1169**，图内矩形可保持原几何位置。

## 三、原位 DXF 制图规则

1. 只在用户指定的产出文件上就地修改；**绝不修改原始图纸**。
2. 字体与编码：
   - 字体 `SimSun.ttf`（与源图 VCTEXT 一致）；
   - DXF R2000、GBK 编码、`$DWGCODEPAGE = ANSI_936`；
   - ezdxf 默认写 ANSI_1252，保存后必须替换，否则中文显示问号。
3. 单位：图外注明"单位：mm"。
4. 尺寸：沿用原图尺寸链；ARCHTICK 斜标记；延伸线偏移 20、超出 40；
   文字在线上方；字高 80；青色（4）；总尺寸在外、分段在内。
5. 图层：规格板白色（7）、参考轮廓灰色（8）、尺寸青色（4）、
   注释白色（7）、轴测单独一层。
6. 文字：不得压在图内或尺寸线上；图外注释用引线（折线 + 小三角箭头）。
7. 板号：保留在板内原位，不移动。
8. 移动文字必须用 `set_placement` 同时更新 `insert` 与 `align_point`；
   只改 `insert` 不会改变渲染位置。

## 四、交付与确认流程

1. 一图一确认：每次只做一个立面，输出该立面的原位 DXF + Excel。
2. 用户核对板件数量、尺寸、位置、注释后，才回填完整版。
3. 未确认前，不重新生成"完整原位 DXF"。
4. Excel 列：编号、房间/位置、材料、长、宽、厚、数量、面积、
   磨边/边部做法、备注、确认度。
5. 待确认项在"确认度"列标注，便于筛选核对。
