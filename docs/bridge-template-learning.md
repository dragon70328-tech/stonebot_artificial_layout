# 桥切板型学习

## 目标

把一份已完成的人工排板 DXF 作为参考语料，学习其中可复用的桥切友好板型，
用于新的零件库存或新的旋转规则。它学习的是“零件组合＋相对摆法”，不会复制
参考图中的编号、坐标或业务分组。

## 入口

```bash
python main.py input.dxf 3000 2000 20 \
  --bridge-template 人工排板结果.dxf \
  --bridge-template-min-fill 0.0 \
  --kerf 5 --sheet-oversize 30,30 \
  --no-confirm
```

当前限制：

- 只支持桥切工艺。
- 要求全部零件属于同一个材料组。
- 暂不支持 `--special-size`。
- 参考板与当前大板尺寸必须一致。

## 使用步骤

1. `learn_template_boards()` 识别参考 DXF 中尺寸等于大板尺寸的闭合矩形。
2. 用零件质心把板内轮廓分配给板框，形成 `TemplateBoard`。
3. 每个模板零件只保留尺寸族和板内相对几何，不保留原编号。
4. `reuse_template_boards()` 按模板利用率从高到低匹配当前零件。
5. 模板零件只有在以下条件全部满足时才接受：
   - 实际几何和模板姿态匹配；
   - 当前零件级 `allowed_rotations` 允许该姿态；
   - 所有零件位于板内；
   - 零件间没有面积重叠。
6. 重放成功的人工板型直接成为热启动板；其余零件继续进入束搜索、LNS 和回看。

只要某个模板有一件无法在当前旋转规则下复现，整张模板即拒绝，不会悄悄改变
零件方向。

## 板型匹配

模板不依赖原始编号。形状族由净面积、长宽和轮廓填充率分桶得到，再通过
bbox 归一化后的 Hausdorff 距离验证实际姿态。这样 CAD 中 0.1～0.2mm 的导出
误差不会破坏匹配，但镜像 L 型或换向 90° 的零件不会被误认。

## 人工板型之外仍保留的搜索

热启动只负责消化能直接复用的高价值板型，不能保证全局最优。剩余零件仍由：

- 多套贪心配置；
- 逐板束搜索；
- LNS 跨板重排；
- `k -> k-1` 压缩；
- 固定朝向局部回看；

共同竞争。最终结果按完整件数、板数、最弱板面积和制造评分比较。

## Fremont 实测

参考人工方案：

- 146张板，708件；
- 平均利用率81.21%；
- 大量板型由22/25英寸同深度横带构成；
- 两件L型反向互补后，用矩形填充缺口。

在保持当前“L+矩形组0°/180°、超2000mm的L-L组90°”规则下：

- 原始自动束搜索：158张；
- 人工板型热启动＋束搜索：157张；
- 再执行零件级合法回看：155张；
- 方案为708件，利用率76.49%，回读和刀路校验通过。

参考人工图本身使用了当前规则不允许的L型方向，因此不能直接把146张布局原样
复制；必须先经过上面的逐件方向校验。
