## 画像要点

- `panel_layers: ["0"]`：封闭图形与房号都在图层 0（无专用编号层）。
- `region_min_side_mm: 1800`：**最小边 ≥1800mm 的封闭图形按"区域轮廓"排除**，
  不作为规格板。实测房间 ≥2500mm、规格板 ≤1500mm，中间有 1000mm 余量，
  阈值取 1800 足够安全。
- `assignment_mode: "containing_region"`：零件的编号由**它落在哪个区域轮廓内**
  决定——先给每个区域找房号文本（插入点落在区域内优先，其次最近且在
  `room_max_distance` 内），再按零件代表点归属到包含它的最小区域；
  没有落在任何区域内的零件回退为"最近房号标签"，避免丢编号。
- `label_pattern: "^(?P<unit>\d{4})$"` + `room_number_format: "{unit}-{index:02d}"`：
  编号形如 `1007-01`（房号 + 组内按 (x, y) 排序的序号）。楼层标签
  `L-10 LEVEL` 等不会被该正则匹配。
- `build_hierarchy: false`：房间轮廓已按区域排除，不能再用"被包含即孔洞"
  的逻辑，否则 3525 件会被整体丢掉。
