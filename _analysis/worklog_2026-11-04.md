# 2026-11-04 工作日志：材料等价池与桥切结构方法

## 目标

把人工排板中的有效方法沉淀为通用能力，不把某一项目的人工排板 DXF
作为测试夹具、默认画像或插件发布内容。

## 材料等价池

- `Part` 新增 `packing_group`，原 `material_group` 保持不变。
- `DrawingProfile.material_equivalence_groups` 可显式声明：

  ```json
  {
    "ST-1+ST-2": ["ST/1", "ST/2"]
  }
  ```

- 排板分组、材料纯度校验、回看减板和并行分批统一使用 `packing_group`；
  未声明等价的材料仍不能共板。
- 确认快照、排板版本、插件上下文和各类 Part 副本同步保留排板池。
- 同一原材料同时映射到多个池时 fail closed，避免静默选错。

## 桥切结构归纳

`src/bridge_template_learning.py` 不再只保存“整张板快照”，新增以下通用方法：

- `complementary_pair`：识别近似补成完整矩形的两件组合；
- `horizontal_band` / `vertical_band`：识别至少三件的同深度横带或同宽列；
- `preserve_relative_pose`：通过模板几何匹配保持组内相对姿态；
- 可选填充件：完整板型库存不足时，最多省略两个已识别的小填充槽；
- 跨板支持统计：按形状族、结构和相对关系统计重复次数；
- 整板平移修复：相对布局只做整板刚体平移，不逐件微移破坏配方。

所有新增测试均使用合成矩形、L 型和小填充件；没有新增客户 DXF 夹具。

## 人造石标准图案纹理效果

- 新增 `src/slab_texture.py`：一种材料/花色登记一张标准可利用区图案，
  同图复用于所有同尺寸大板。
- 图案图片严格映射到 `SheetSpec.usable_*`，不包含让尺；尺寸或宽高比不符
  直接拒绝。
- 按排板实际位置从标准图案采样，撤销零件级排板旋转后，按原位轮廓生成
  RGBA 纹理；孔洞区域透明。
- 在原位编号 DXF 上叠加 `TEXTURE_IMAGE` 图层，按编号匹配并设置多边形
  裁剪边界，不修改原有轮廓、标注和单位。
- 输出纹理 DXF、逐件 PNG、整板预览和内容摘要 manifest。
- CLI 增加 `--texture-patterns`、`--texture-output`、`--output-root`；
  MCP 增加 `stonebot_generate_textured_drawing`，仅允许在任务完成后调用。
- Pillow 加入运行时依赖。
