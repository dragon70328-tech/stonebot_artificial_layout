## 补充：SaaS 对话式编排要求

- 上传后先检查参数是否齐全；缺大板尺寸、厚度、加工方式、kerf、旋转限制、是否包含无编号件等，必须主动询问。
- 参数齐全后先读图、匹配画像、审图、编号，并生成 `*_numbered_原位.dxf` 供用户确认。
- 用户确认编号前不得进入排板；确认后再执行 `nest_parts`。
- 排板完成先报告板数，用户确认后再后处理和写最终 DXF/报告。
- 阶段顺序建议：
  `uploaded -> 参数校验 -> analyze_drawing -> match_profile -> read_dxf -> audit_drawing -> assign_numbers -> write_numbered_dxf -> 用户确认编号 -> numbering_confirmed -> nest_parts -> nested_reported -> 用户确认板数 -> postprocess -> postprocess_confirmed -> write_dxf/write_report -> completed`
