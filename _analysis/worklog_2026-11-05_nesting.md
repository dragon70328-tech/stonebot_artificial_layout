# 2026-11-05 ST-8 排板优化记录

## 结果

- 输入：`citizen_ST-08_全部2018_numbered_原位.dxf`
- 件数：2018
- 大板：3200 x 1600 mm，禁止旋转
- 上一版：585 张 / 73.637%
- 当前版：**578 张 / 74.53%**
- 较 585 张减少：7 张

## 优化路径

1. 固定朝向 MaxRects 快通道生成 585 张候选。
2. 逐板束搜索生成 580 张候选。
3. 把两套候选产生的全部有效板型转换为整数变量，在每种规格数量精确相等的
   前提下，用 HiGHS 求最少板型配比，得到 578 张。
4. 按统一布局键选择最终方案。

优化器统计：

```text
rect_fast_sheets = 585
beam_sheets = 580
pattern_integer_sheets = 578
selected_layout_path = pattern_integer
```

## 后续

下一步目标是 575 张。需要生成现有候选库之外的新板型，重点是：

- 小件横向配宽；
- 长件板下方余带的组合；
- 跨板尾件再平衡。

本轮已额外生成 1302 种固定朝向候选板型再次求解，目标仍为 578 张；
继续扩充同类排列候选已无收益，后续需要引入新的几何组合生成方式。
