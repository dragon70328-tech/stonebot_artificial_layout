## 讨论内容

### 1. 项目理解回顾

完整审阅了项目全部核心模块：

| 模块 | 职责 |
|------|------|
| `main.py` | CLI 入口（argparse + 交互模式） |
| `template_v3.py` | 模板排板：以历史排板结果对号入座 |
| `src/models.py` | Part / Sheet / NestingResult 数据模型 |
| `src/dxf_reader.py` | DXF 读取 + 层级构建 + 编号匹配（containment-first / nearest-match） |
| `src/dxf_writer.py` | DXF 写入（排板结果 + 编号检查，GROUP 组织） |
| `src/nesting.py` | 排板引擎：多轮贪心 BFD + LNS 优化，DE-9IM 精确校验 |
| `src/numbering.py` | 编号管理（原编号保留 / P-XXXX 自动生成） |
| `src/units.py` | 公制/英制切换 |

核心流程 6 步：读取 DXF → 构建层级 → 匹配编号 → 编号检查 DXF → 排板 → 输出排板 DXF

### 2. 本体约束（Ontology Constraints）方向

用结构化规则表达石材台面排板的领域知识，分四层：

| 层级 | 内容 | 实现方式 |
|------|------|----------|
| 实体约束 | 面板最小面积、孔洞最大占比、有效形状定义 | Pydantic validators / dataclass __post_init__ |
| 工艺约束 | 纹理方向限制、最小间距、边缘余量 | 新增 src/constraints.py 约束规则引擎 |
| 材料约束 | 石英石/花岗岩厚度范围、大板标准规格库 | JSON/YAML 配置文件 config/materials.json |
| 排板约束 | 同户型面板同板、颜色/批次一致性 | nesting.py 的 sort key / grouping 逻辑增强 |
