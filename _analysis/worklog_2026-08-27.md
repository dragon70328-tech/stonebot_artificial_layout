## kerf 化与生产口径（2026-08-27 晚）

用户锁定生产口径：大板可用尺寸 = 标称 + 30mm 让尺（2530x1430 / 2430x1230），
锯缝 kerf = 5mm，零件为净尺寸（1197 为实际尺寸），目标总板面积最小。

### 实现

- 新增 `src/strip_packing.py`：精确窄条 packer，在放大空间（件 +5、板 +5、
  零间隙相邻 = 件间 5mm 缝）工作。`exact_bin_pack`（模式枚举 + DFS set-cover
  + 记忆化 + BFD 兜底 + `_extract_big_lengths` 剥离 >cap/2 长度）；
  `pack_residual_strips`（竖列/横排、单/双板型、剥离与非剥离双路评优）。
- `src/list_nesting.py`：新增 v3 候选 `_pack_group_large_then_strips_v3`
  （spread 配对大件 -> 仁霸填充 -> 精确剩余 packer），挂入
  `_nest_group_rect_multi`；`run_list_nesting` 新增 `kerf_mm` / `oversize_mm`，
  `_inflate_items` / `_deflate_results` 边界转换，`_billing_summary_lines`
  输出标称计价口径。
- `main.py` 新增 `--kerf` / `--oversize`。
- 新增 `tests/test_strip_packing.py`（5 个测试）。
- 新增 `_analysis/validate_st104_kerf.py`：放大空间 + 净尺寸空间双向几何校验。

### 关键 bug 修复

`_fill_free_rect_renba` 三处硬编码 95（行列数与 bottom_height），kerf 化后
节距为 100 导致多放一排/一列，产生 5 处越界 + 2 处重叠。修复：新增
`lane_width` 参数（默认 95.0 保持旧行为），调用点传入实际 `strip_width`。

### 结论

- 生产口径 `--sizes 2400x1200,2500x1400 --kerf 5 --oversize 30`：
  **122 张**（60 张 2430x1230 + 62 张 2530x1430），可用面积 403.644 m²，
  出材率 94.2%；标称计价 389.800 m²。
- 校验：1229/1229 件全排，越界 0，重叠 0，净尺寸空间最小间距恰为 5.000mm。
- 名义口径（无 kerf/让尺）：**121 张**（60 张 2400x1200 + 61 张 2500x1400），
  386.300 m²，98.4%，已追平仁霸张数（121）。
- 生产口径 122 vs 仁霸 121 的差距在填充协调：仁霸式填充只往大件板余料塞了
  约 12 m² 窄条（理论可容 ~19 m²）；剩余窄条若降到 ~655 列即可 28 张全小板
  收场，总数 121。方向：大件余料优先吃短条，1197 留给剩余小板
  （1197/1200 = 99.75% 完美列公民）。
- 回归测试：`python -X utf8 -m pytest -q` -> `101 passed`。
