# Worklog 2026-11-06

## Circular-saw clearance rule

Confirmed manufacturing formula:

```text
H = sheet thickness + 2mm
clearance = sqrt(saw diameter * H - H * H)
```

For `D=350mm`, `T=20mm`: `H=22mm`, clearance `84.947mm`.

The clearance is a local blade-body check at pronounced outer reflex cut
points.  It is not a global part gap, not kerf, and not sheet oversize.
Minimum sheet count always takes precedence; saw clearance is compared only
among layouts with the same sheet count.

## Manual layout propagation

Added:

- `src/layout_adjustment.py`;
- `scripts/apply_layout_adjustment.py`;
- MCP tool `stonebot_propagate_layout_adjustment`;
- `docs/layout-adjustment-propagation.md`.

The user edits one reference `Sheet_n` in a copied nested DXF.  The system
matches identical part-shape inventories, translates whole GROUPs to the
reference relative poses, validates each target sheet, and skips unsafe
targets atomically.  It does not rotate, reshape or renumber parts and does
not change sheet count.

## Automatic same-sheet-count repair

Added:

- `src/saw_repair.py`;
- `scripts/repair_saw_clearance.py`;
- MCP tools `stonebot_audit_saw_clearance` and
  `stonebot_repair_saw_clearance`;
- automatic repair after post-processing and sheet reduction whenever
  `--circular-saw-diameter` is supplied.

The repair translates whole parts only and accepts a move only when the local
saw score improves while bounds, overlap and minimum gap remain valid.  It
never changes sheet count or part inventory.  Unresolvable sheets stay
unchanged and are reported.
