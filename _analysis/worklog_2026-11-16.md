# Worklog 2026-11-16

## Local Runtime foundation

Continued on branch `codex/local-runtime-v1`:

- added per-user Runtime layout under `%LOCALAPPDATA%\StoneBot` with
  `STONEBOT_LOCAL_ROOT` override;
- added an OS-level single-instance file lock;
- added `scripts/run_local_runtime.py` using the local data root;
- added checksum-verified task capsules with manifest validation, path traversal
  protection, duplicate detection, atomic extraction and exact path remapping;
- added explicit MCP tools for task capsule export/import;
- integrated capsule export/import with `PluginJobService`, including workflow
  session, confirmed drawing, JobContext snapshot, artifact files and nesting
  revision paths;
- verified importing an analysed Snow White job into a fresh Runtime data root
  restores the same audited stage and six parts.

Current transfer is explicit file-based operation. Online sync, account-owned
storage, encryption envelopes and single-writer job leases remain follow-up
work.

## Secure update foundation

- added `cryptography` and locked Ed25519 support;

  protection, exact inventory verification and optional self-test callback;

Windows Authenticode signing, update UI, detached updater helper and data
migration remain release-engineering follow-up work.

## Local licensing foundation

- added stable per-installation device identity under the local Runtime root;
