## 两次排板对比分析

| 对比维度 | CGR45 | 水星项目1 |
|----------|-------|-----------|
| 图纸来源 | 未知制图者 | 不同制图者 |
| 图层结构 | 多图层（编号/规格板分离） | 单图层（全部在图层 0） |
| 编号方式 | TEXT 实体 on "编号" 层 | MTEXT 实体 on 图层 0（户型分类标签） |
| 面板数 | 203 | 1,201 |
| 孔洞 | 306 个（111 块带孔） | 0 个 |
| 面板复杂度 | 不规则形状+盆孔/龙头孔 | 多为矩形，较规整 |
| 闭合状态 | 全部正确闭合 | 86 条缺闭合边（gap ~644.5mm） |
| 多段线顶点 | 正常 | 含 6 条 2 顶点残留线段 |
| 大板 | 3200×1800 | 3200×1600 |
| 使用张数 | 50 | 123 |
| 出材率 | 73.0% | 84.2% |

### 制图差异导致的问题

1. **图层规范不一致**：CGR45 按 CAD 规范分层（编号层、规格板层分离）；水星项目1 全部放在图层 0，需手动指定 panel_layers=["0"]
2. **文字实体类型**：CGR45 用 TEXT；水星项目1 用 MTEXT（带富文本格式），需用 plain_text() 提取
3. **编号语义不同**：CGR45 是逐块唯一编号（如 405-A）；水星项目1 是户型分类标签（如"E厨房"），同户型多块面板共享同一标签，无法 1:1 匹配
4. **闭合质量**：水星项目1 的 86 条面板缺闭合边，需放宽 _is_closed 判定
5. **面板规模**：1,201 vs 203，数量级差异大，排板耗时显著增加
6. **形状复杂度**：CGR45 含大量异形面板+孔洞，出材率较低；水星项目1 多为规整矩形，出材率较高

### 待改进
- 编号系统需支持"户型标签 + 序号"模式（如 E厨房-1~E厨房-36）
- 大规模排板（>1000 块）需优化算法或增加超时保护

- 输出: output/CGR45final_nested_3200x1800.dxf + CGR45final_report_3200x1800.json

## 关键经验（模板排板）
1. 从排板结果 DXF 反解析时，编号关联必须用"文字点在多边形内"（contains），不能用质心最近距离——L/U 形大板质心偏移，编号会被盆孔/龙头孔（35x35 小多边形）抢走
2. 旋转角度判定用 IoU 形状重合度（4 角度 x 3 种对齐取最优），比包围盒宽高比可靠
3. 圆角简化导致的毫米级干涉（<30 mm2）用"链式平移"修复：被挡的相邻板一起向空档方向整体移动（如 Sheet 16 的 405-B+419-B 整体 +x 8mm）
4. 贪心算法在临界填充率下不稳定（50/51 张漂移），老项目改版优先套模板而非重排
