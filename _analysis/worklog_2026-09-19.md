# 工作日志 2026-09-19

## 主题

继续 2026-09-18 的原位 DXF 纠错闭环，优先完成“在线预览并直接点击实体”能力。

## 已完成

1. 新增 `src/drawing_preview.py`：
   - 从当前 `JobContext` 统一导出面板外轮廓、孔洞和未识别封闭实体；
   - 将 DXF 坐标转换为 SVG 预览坐标，保留原始边界信息；
   - 每个可点击实体都带有与纠正工具一致的稳定 `target_id`；
   - 支持 Polygon、MultiPolygon 和 GeometryCollection 的预览拆解。
2. `build_correction_context` 为面板和孔洞补充 `target_id`，前端不再依赖编号或其他临时字段拼接目标。
3. 新增 `GET /jobs/{job_id}/drawing-preview`：
   - 返回版本号、画布 viewBox、实体统计和可点击几何；
   - 面板、孔洞、未识别实体的颜色和角色信息完整；
   - 视图和下载均受现有租户与 operator 权限约束。
4. 识图排板页新增原位 DXF 在线预览：
   - 蓝色规格板、橙色孔洞、红色虚线未识别实体；
   - 单击图形直接选中/取消纠错目标；
   - 在线预览与原有纠错目标多选列表双向同步；
   - 支持滚轮缩放、放大/缩小和适应全图；
   - 可直接下载当前版本的原位编号 DXF；
   - 面板编号显示在轮廓中心，选中目标以黄色高亮。
5. 保留原有列表选择作为回退，不破坏已有对话和纠正操作流程。
6. 新增 Python、HTTP 和前端纯逻辑测试。

## 阶段 3：图层弱化与多证据识别（已实施）

1. 新增 `src/entity_classifier.py`：
   - 综合几何面积、周长、顶点数、圆整度、面积分位、包含关系和编号文本；
   - 图层命中仅作为有限加分，不再单独决定角色；
   - 输出 `panel / hole / unknown`、置信度、分值和可审计原因。
2. `extract_closed_entity_candidates` 新增 `layer_filter_mode`：
   - `strict` 保留旧行为；
   - `hint` 保留所有封闭实体，把图层信息交给分类器；
   - 画像标准读图路径切换到 `hint` 模式。

   - 未知图层中的大型非圆轮廓仍可成为面板；
   - 孔洞可按包含关系和几何特征识别，不再必须依赖 `hole_layers`；
   - 编号文本位于孔洞内时，编号归属使用外轮廓兜底。
4. 编号文本收集增加全图正则回退：
   - 优先使用 `number_layers`；
   - 当编号层改名或完全没有命中时，按 `label_pattern` 全图查找；
   - 仍然只接受严格匹配编号模式的文本。
5. `RecognizedPanel.properties` 保留分类证据，后续审图界面可以显示“为什么这样判断”。
6. 新增图层扰动回归测试：
   - 面板层、孔洞层、编号层全部改名；
   - 验证仍能恢复 2 块面板、1 个孔洞和 2 个编号；

## 阶段 8：模型对比与漂移监控（已实施）

1. 新增模型评估能力：
   - `evaluate_model_on_samples` 评估任一模型在反馈样本上的指标；
   - `compare_recognition_models` 对比当前模型和候选模型；
   - 候选模型不得在准确率、精确率、召回率上明显退化。
2. 新增特征漂移检测 `detect_feature_drift`：
   - 比较最近反馈特征均值与模型训练时均值和尺度；
   - 识别面积、长宽比、顶点数、圆整度、CIRCLE 特征漂移；
   - 漂移报告包含具体漂移特征和最大标准化偏移。
3. 训练激活流程增加回归门：
   - 绝对质量门通过后，还要通过相对当前模型的回归门；
   - 当前模型不存在时只执行绝对质量门；
   - `latest_training.json` 记录对比结果和漂移状态。
4. 新增 `scripts/monitor_recognition_model.py`：
   - 评估当前模型和可选候选模型；
   - 输出 `recognition_models/monitoring/latest.json`；
   - 检测到漂移时返回非零退出码，便于定时任务告警。

## 实图反馈修复：东莞奥特莱斯2（用户复核 02B-17 + 跨板减板）

用户反馈两条：① `02B-17` 的图形是错的；② 后处理没有回看排板 DXF，sheet 7 与 sheet 30
内的规格板本可以合并到一张板。

### 问题一：开口轮廓被"硬补"或被丢弃

- `02B-17` 对应实体 handle `2985`，是**开口** LWPOLYLINE：4 个角点都画了，
  但没有画回第一条边，缺口 704mm。全图 `石材分缝` 层共 1109 个轮廓，其中 65 个是开口的
  （缺口 42~1079mm）。
- 画像 `closed_tolerance=1500` 会按两端点直线强制闭合 → 保住了零件，但凭空多出一条
  704mm 斜边（用户看到的"错图"）。
- 早前把候选闭合容差收紧到 10mm 之后，这 65 件被**整体丢掉**（1109 → 1044 件），
  属于更严重的静默丢件。
- 判定依据：按共线/距离 1/3/10mm 全图搜索，源图中**没有任何实体**提供这条闭合边；
  65 件闭合后与原已识别件**零重叠**，且并集无内部孔洞 —— 说明"两端点直线闭合"
  是最合理的最佳推测，但必须由人确认。

处理：

1. 恢复画像闭合容差参与候选提取（不再整体丢弃开口轮廓）。
2. `dxf_reader.extract_closed_entity_candidates` 记录每条候选的 `closure_gap`。
3. `closure_gap` 贯通 `parts_data` → `Part.closure_gap` → 识别契约 `properties`。
4. 编号检查 DXF 增加 `CHECK_CLOSURE` 图层（橙色）：把未闭合轮廓和
   "未闭合：缺口 704mm" 标注画在原位，方便在 CAD 里逐件核对。
5. 运行与报告显式提示：`注意：65 个轮廓未闭合，已按两端点直线强制闭合，请核对原位 DXF`，
   并写入 `*_postprocess_check.json` 与报告 JSON 的 `forced_closure_parts`。

### 问题二：后处理没有回看排板结果

- 新增"回看减板"：**后处理之后**基于压实后的图形，把低占用板的零件搬进其它板空位，
  能减一张就减一张，再报板数。
- 安全约束：不跨材料组、按 `min_gap` 留间隙（`clearance` 侵蚀自由空间）、
  减板后重新压实并跑 `validate_mixed_nesting`，校验不通过即回退原排板。
- 入口：默认开启，`--no-auto-review` 关闭，`--review-budget` 控制总时间（默认 120s）。
- 同时修复回看回读丢材料分组（`load_nested_dxf` 从编号前缀恢复 `material_group`），
  之前会把 04B 的件错误并进 01B 的板。
- 性能：placement 搜索里对每个候选点重复 `free_poly.buffer(0.01)` 是热点，
  改为每个空闲区只 buffer/prepare 一次，单板搜索 162s → 9s（约 13 倍）；
  并给 DFS 加 deadline/per-donor 预算，避免单个 donor 卡死整轮。

### 遗留问题

1. 65 件强制闭合件需要人工在原件里补齐（或提供正确形状），补好后本系统按新图重算即可；
