# 工作日志 2026-09-19

## 主题

继续 2026-09-18 的原位 DXF 纠错闭环，优先完成“在线预览并直接点击实体”能力。

## 已完成

1. 新增 `src/drawing_preview.py`：
   - 从当前 `JobContext` 统一导出面板外轮廓、孔洞和未识别封闭实体；
   - 将 DXF 坐标转换为 SVG 预览坐标，保留原始边界信息；
   - 每个可点击实体都带有与纠正工具一致的稳定 `target_id`；
   - 支持 Polygon、MultiPolygon 和 GeometryCollection 的预览拆解。
2. `build_correction_context` 为面板和孔洞补充 `target_id`，前端不再依赖编号或其他临时字段拼接目标。
3. 新增 `GET /jobs/{job_id}/drawing-preview`：
   - 返回版本号、画布 viewBox、实体统计和可点击几何；
   - 面板、孔洞、未识别实体的颜色和角色信息完整；
   - 视图和下载均受现有租户与 operator 权限约束。
4. 识图排板页新增原位 DXF 在线预览：
   - 蓝色规格板、橙色孔洞、红色虚线未识别实体；
   - 单击图形直接选中/取消纠错目标；
   - 在线预览与原有纠错目标多选列表双向同步；
   - 支持滚轮缩放、放大/缩小和适应全图；
   - 可直接下载当前版本的原位编号 DXF；
   - 面板编号显示在轮廓中心，选中目标以黄色高亮。
5. 保留原有列表选择作为回退，不破坏已有对话和纠正操作流程。
6. 新增 Python、HTTP 和前端纯逻辑测试。

## 阶段 3：图层弱化与多证据识别（已实施）

1. 新增 `src/entity_classifier.py`：
   - 综合几何面积、周长、顶点数、圆整度、面积分位、包含关系和编号文本；
   - 图层命中仅作为有限加分，不再单独决定角色；
   - 输出 `panel / hole / unknown`、置信度、分值和可审计原因。
2. `extract_closed_entity_candidates` 新增 `layer_filter_mode`：
   - `strict` 保留旧行为；
   - `hint` 保留所有封闭实体，把图层信息交给分类器；
   - 画像标准读图路径切换到 `hint` 模式。
3. `_extract_profile_panels` 改为先分类候选，再构建面板/孔洞层级：
   - 未知图层中的大型非圆轮廓仍可成为面板；
   - 孔洞可按包含关系和几何特征识别，不再必须依赖 `hole_layers`；
   - 编号文本位于孔洞内时，编号归属使用外轮廓兜底。
4. 编号文本收集增加全图正则回退：
   - 优先使用 `number_layers`；
   - 当编号层改名或完全没有命中时，按 `label_pattern` 全图查找；
   - 仍然只接受严格匹配编号模式的文本。
5. `RecognizedPanel.properties` 保留分类证据，后续审图界面可以显示“为什么这样判断”。
6. 新增图层扰动回归测试：
   - 面板层、孔洞层、编号层全部改名；
   - 验证仍能恢复 2 块面板、1 个孔洞和 2 个编号；
   - 同时覆盖 `build_hierarchy=True/False`。

## 阶段 8：模型对比与漂移监控（已实施）

1. 新增模型评估能力：
   - `evaluate_model_on_samples` 评估任一模型在反馈样本上的指标；
   - `compare_recognition_models` 对比当前模型和候选模型；
   - 候选模型不得在准确率、精确率、召回率上明显退化。
2. 新增特征漂移检测 `detect_feature_drift`：
   - 比较最近反馈特征均值与模型训练时均值和尺度；
   - 识别面积、长宽比、顶点数、圆整度、CIRCLE 特征漂移；
   - 漂移报告包含具体漂移特征和最大标准化偏移。
3. 训练激活流程增加回归门：
   - 绝对质量门通过后，还要通过相对当前模型的回归门；
   - 当前模型不存在时只执行绝对质量门；
   - `latest_training.json` 记录对比结果和漂移状态。
4. 新增 `scripts/monitor_recognition_model.py`：
   - 评估当前模型和可选候选模型；
   - 输出 `recognition_models/monitoring/latest.json`；
   - 检测到漂移时返回非零退出码，便于定时任务告警。
