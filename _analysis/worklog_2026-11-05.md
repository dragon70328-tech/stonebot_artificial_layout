# 2026-11-05 工作日志：人造石纹理生产化

## 目标

把已能生成纹理的试验能力补齐为可移动、可复用、可由已有排板补做，并能从
MCP/HTTP/门户调用的生产功能。

## 可移动交付

- `generate_textured_package` 增加 `image_reference_mode`：
  - `absolute`：AutoCAD 2023 本机直接可见；
  - `relative`：用于可移动包。
- `create_archive=True` 同时生成：
  - 绝对路径主 DXF；
  - `*_可移动.dxf`；
  - 完整 `textures/`、`previews/`、manifest；
  - ZIP 成果包。
- 新增 `relocate_texture_references()` 和
  `scripts/relocate_texture_dxf.py`，移动到新目录后可批量改写 IMAGEDEF。
- 新增 `scripts/generate_slab_texture.py`：从已有排板 DXF + 原位编号 DXF
  补做纹理，默认输出到排板 DXF 同一级目录。

## 图案资产库

- 新增 `src/slab_pattern_library.py` 与
  `scripts/slab_pattern_library.py`。
- 支持 register/list/validate。
- 图片复制到 `slab_patterns/images/`；客户图片默认被 Git 忽略。
- `library.json` 可直接作为 `--texture-patterns` 输入。

## MCP / HTTP / 门户

- MCP 纹理工具增加 `image_reference_mode` 和 `archive`。
- HTTP 增加：
  - `POST /texture-assets/{filename}`
  - `POST /jobs/{job_id}/textures`
- 纹理生成进入后台任务队列，成果进入 session artifacts，可通过现有下载接口获取。
- 门户增加“人造石纹理效果”面板：上传标准图/图案清单、选择引用模式、
  生成 ZIP，并轮询后台任务完成状态。

## 验证

- 纹理核心、图案库、MCP、插件和 HTTP 定向测试均通过。
- 前端逻辑测试 18 passed。

## ST-8 基准核对

- 执行计划中的 570 张对应旧版 1946 件，73.35%。
- 当前 `citizen_ST-08_全部2018_numbered_原位.dxf`：
  - 2018 件，总面积 2205.59 m²；
  - 现有分板清单 588 张，73.262%；
  - 面积下界 431 张。
- 当前 `rect_fast_layout` 只在允许 90° 旋转时生成板型；`--no-rotation`
  会退回慢速通用路径。历史 `fixed_orientation_rect_fast` 能力需要恢复。
- 固定朝向 MaxRects 原型最好为 585 张，仅改善 3 张，且尚不保证桥切切序，
  因此没有接入生产。
- 固定朝向桥切 shelf/row 原型：
  - 简单 FIFO shelf 为 592 张；
  - 按高度精确分行后 624 张；
  - 加入整组 BFD 分行后 628 张；
  - 均明显差于 588 张，说明不能只恢复一个简单快通道，还需要板型配方和
    跨板尾料组合。
- 将 MaxRects 的 587/585 候选生成真实 DXF：
  - 585：2018 件，73.637%；
  - 几何越界/重叠 0，刀缝材料校验错误 0，DXF 回读错误 0；
  - 但 585 有 **529/585** 张板不满足 guillotine 切序；
  - 587 有 **531/587** 张不满足；
  - 因此两个候选均不能作为桥切正式方案。桥切优化必须约束为可切片板型，
    不能仅按矩形不重叠选优。

### 工艺优先级调整

- 用户明确：**省料优先于 guillotine 切序**。
- `rect_fast_layout` 已在禁止旋转且全矩形时接入固定朝向 MaxRects
  多策略候选；ST-8 2018 件实测 **585 张 / 73.637% / 约 3 秒**。
- 生产 CLI 完整跑通：
  - 2018 件 / 585 张 / 73.64%；
  - 排板 3.9 秒，后处理靠边/通切/间距全部通过；
  - 输出排板 DXF 约 1.8 MB；
  - 排板后原始候选有 44 张板需要非 guillotine 切序，但**后处理推边后
    最终 585 张全部通过 guillotine 检查**（0 张非 guillotine）；
  - 之前实验脚本的 529 张非 guillotine 是另一版自由 MaxRects 原型，
    不能与生产候选混用。
- 非 guillotine 板数写入 optimizer stats；不再作为单独拒绝条件。
- 新增 `rectangles_are_guillotine` 用于诊断和后续切序规划。
